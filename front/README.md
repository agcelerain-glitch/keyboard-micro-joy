# keyboard-micro-joy — front

React + TypeScript + Vite によるフロントエンド。  
プロジェクト全体の説明は [../README.md](../README.md) を参照。

## コマンド

```bash
npm install        # 依存インストール
npm run dev        # 開発サーバー (http://localhost:5173)
npm run build      # プロダクションビルド
npm run tauri dev  # Tauri デスクトップ版（要 Rust）
npm run tauri build  # Tauri リリースビルド
```
